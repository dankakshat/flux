# 🌑 Flux — Minimalist Deep Work App

A sleek, dark-themed **focus web app** designed for deep work, built with simplicity and aesthetics in mind.

> ✨ Designed for creators, coders, and students who want zero distractions and maximum clarity.

---

## 🚀 Live Demo

👉 [View Live Project](https://dankakshat.github.io/flux)

---

## 🖤 Features

* ⏳ **Pomodoro Timer**

  * Custom work & break durations
  * Auto-switch sessions
  * Smooth progress animation

* ✅ **Task Manager**

  * Add / delete / complete tasks
  * Persistent storage using localStorage

* 🎥 **Aesthetic Background**

  * Fullscreen video background ( soon )
  * Gradient fallback mode
  * Adjustable blur/dim effect

* 🎯 **Focus Mode**

  * Distraction-free full-screen experience

* 📊 **Productivity Stats**

  * Track completed sessions
  * Total focus time

* ⚡ **Keyboard Shortcuts**

  * Spacebar → Start/Pause


---

## 🌐 Deployment (GitHub Pages)

1. Push your project to GitHub
2. Go to **Settings → Pages**
3. Under "Source", select:

   * Branch: `main`
   * Folder: `/root`
4. Click **Save**

Your app will be live at:

```
https://dankakshat.github.io/flux
```
